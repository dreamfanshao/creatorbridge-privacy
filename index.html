椰子博主 / CreatorBridge

隐私政策

更新及生效日期：2026 年 10 月 19 日

本政策适用于“椰子博主”Microsoft Edge 扩展程序及同功能的 Chrome 版本（原名称“椰子找博主”、CreatorBridge）及其后端服务 creatorbridge.meixuanai.cn，说明我们如何处理与查找小红书、抖音相似博主以及 Instagram 推荐方向浏览有关的数据。

插件通过读取博主页面中已加载的信息生成关键词，按您确认的关键词搜索，并帮助您逐个筛选和收藏博主。无需注册邮箱或手机号；系统使用匿名身份区分不同用户的数据。匿名身份仍是可关联的用户标识，并不代表完全不处理用户数据。
处理哪些数据服务商与共享存储与保留您的选择联系我们

一、我们处理哪些数据及其用途

网站访问范围：0.8.12 起的普通商店发布包仅申请小红书、抖音网站及本插件后端的访问权限，页面识别和辅助脚本仅在支持的平台运行，不读取其他网站的正文。

  • 当前博主和作品信息：在支持的平台页面识别博主，读取已加载的昵称、平台用户标识、主页或作品链接、头像链接、简介、作品标题或视频文案、已加载的作品封面链接，以及页面可取得的粉丝数、点赞数等信息。用于展示当前博主、生成关键词和筛选搜索结果。视频分析依据已加载的文字信息，不下载视频进行音视频识别。
  • 关键词和操作数据：您确认或手动输入的关键词、搜索平台及页数，用于向搜索服务查询作品并整理作者结果；项目名称、收藏的博主信息及收藏时间用于项目管理；跳过状态、搜索结果和筛选进度用于恢复当前操作。
  • 匿名身份及会话：系统创建匿名用户 ID，并在扩展本地存储中保存访问令牌、刷新令牌等会话凭据，用于再次打开插件时恢复身份、验证请求，以及隔离不同用户的项目与收藏。
  • 必要的运行记录：后端记录关联匿名 ID 的调用时间、次数、额度、请求标识、错误码、状态码和耗时，用于额度控制、防止滥用和故障排查。服务器及基础设施也可能在访问、安全日志中记录 IP 地址、请求路径、时间、浏览器信息和响应状态。
  • 每日活跃人数：在插件功能请求通过身份验证后，后端保存北京时间日期及匿名身份 ID 的哈希摘要，用于统计每天使用服务的人数；同一身份当天只计一次，不在此统计中保存请求正文。
  • 免费次数与微信解锁：后端按匿名 ID 记录已使用的免费次数，以及您输入的解锁码、兑换时间和解锁状态。解锁码由我们生成，您可自愿添加客服微信获取。插件不读取您的微信账号或好友信息，服务端不保存您的微信号。

页面识别和登录提示关闭脚本在受支持的平台页面运行；当您使用关键词生成功能时，相关页面信息会发送到本插件后端；确认开始搜索后，关键词才会发送给搜索服务。筛选时可能预加载下一位博主页面，因此会向对应平台发送正常的页面请求。

我们不读取您的小红书、抖音账号密码或登录 Cookie，不收集私信，不使用浏览器历史记录 API 获取完整浏览记录。页面简介或标题本身可能包含博主公开的个人信息，请勿在手动输入内容中添加密码、身份证号等与搜索无关的敏感信息。

Instagram 推荐方向浏览（仅实验版本）

0.8.12 起的普通商店发布包不包含此功能、实验脚本或 Instagram 网站访问权限。以下说明仅适用于另外启用该功能的实验版本。

此功能在您主动授予 Instagram 网站访问权限、绑定标签页并开始一轮后运行。插件通过页面上的登录账号入口核对账号，读取公开页面中可见的帖子链接、文案和图片说明，在本机按您确认的关键词和语言筛选内容，并执行站内搜索及浏览。插件不读取账号密码、登录 Cookie 或私信，不调用 Instagram 私有接口。遇到登录、验证、账号变化或无法识别的页面时停止。

只有点击“生成搜索计划”时，您填写的目标方向才会经现有后端发送给阿里云百炼 / 通义千问；Instagram 页面内容和账号标识不会作为计划输入发送给模型。模型请求沿用匿名身份验证、额度及必要运行记录。直接使用预设或手动填写计划无需调用模型。

浏览器本地保存最近使用的计划和最近 10 轮记录，包括账号名、方向、操作时间、帖子链接、匹配词、浏览及收藏计数、推荐页抽样汇总。原始帖子文案不保存在这些记录中。您可清除本机推荐记录；最近使用的计划保留，清除扩展数据或卸载插件可一并移除。

默认只搜索和浏览；只有勾选“自动收藏”才会在 Instagram 收藏匹配的帖子。搜索、浏览和收藏会由 Instagram 按其自身规则处理。清除本机记录不会撤销 Instagram 收藏；请在 Instagram 中管理收藏。推荐由 Instagram 决定，插件不承诺推荐变化的比例或时间。

二、数据传输与第三方服务

实现上述功能需要将相关数据发送到后端和以下服务。数据传输采用 HTTPS；第三方按其适用服务条款和隐私政策处理收到的数据。

服务商处理的数据与目的
阿里云（后端托管）承载插件后端，处理身份验证请求、页面分析输入、关键词、项目和收藏请求，以及必要的运行、安全记录。当前后端部署在中国大陆。
Supabase（身份与数据库）处理匿名身份、会话验证及项目、收藏数据，提供身份恢复和按用户隔离的云端存储。
阿里云百炼 / 通义千问（AI）接收所选平台、博主简介、已加载的作品标题或文案，以及最多 8 张作品封面，用于结合图文生成相关关键词。当前发送前会去除简介中的可识别网址和邮箱，但不保证原文中的所有个人信息都被去除。匿名会话凭据、项目及收藏列表不会作为关键词分析提示发送。
EveryInfra（api.everyinfra.com，搜索服务）接收搜索关键词、分页及必要搜索参数，返回小红书或抖音作品、作品链接与作者信息。不会为此发送您的匿名会话凭据或收藏列表。
小红书、抖音及其图片服务当您打开或预加载主页、作品或头像图片时，对应平台接收正常网页或图片请求，并按其自身政策处理网络请求信息和平台登录状态。

Supabase 及其他第三方云服务可能在中国大陆以外的地区处理或存储数据，不能将本服务理解为所有数据均仅存储在境内。我们会在新增数据接收方或实质改变处理目的前更新披露，并在适用情况下取得所需同意。

三、使用范围与保护措施

我们仅将上述数据用于查找相似博主、项目与收藏管理、您主动开启的 Instagram 推荐方向浏览，以及这些功能必要的安全、额度和可靠性维护。我们不出售用户数据，不用于个性化广告、信用评估或贷款，不用于与插件单一用途无关的用户画像。

Microsoft Edge 版本依据 Microsoft Edge Add-ons 开发者政策处理用户数据；Chrome 版本依据 Chrome Web Store 用户数据政策及 Limited Use（有限使用）要求处理用户数据。两种浏览器版本均仅为明确说明的用户功能处理必要数据。除提供功能所必需的服务商处理外，仅在履行法律义务、处理安全或滥用事件等允许的情况下披露必要数据。工作人员仅在获得您对特定支持请求的授权、安全调查或法律要求等必要情形下访问相关数据。

云端项目与收藏通过经验证的匿名身份和数据库访问规则隔离；后台管理设置需要管理员验证。我们采取合理措施保护数据，但任何网络传输和存储都不能保证绝对安全。

四、存储位置与保留期限

  • 浏览器本地：匿名会话和项目选择等保存在扩展本地存储；搜索及筛选临时状态保存在扩展会话存储。清除扩展数据、卸载或浏览器会话结束可能分别清除这些状态。
  • 云端身份、项目和收藏：保留以支持后续使用，直至您删除相关收藏、提出并完成数据删除请求，或服务停止后不再需要保留。当前没有自动按固定天数删除所有项目的机制。
  • 运行记录：额度明细定期清理超过 32 天的记录；不含用户标识的服务累计用量汇总持续保留，不随明细清理而减少。精简错误诊断保留最近 7 天且最多 10,000 条；后台管理操作审计定期清理超过 90 天的记录。定时清理可能存在执行间隔。当前生产服务不生成包含完整搜索请求、响应的逐次查询日志。
  • 日活统计：日期与匿名身份 ID 哈希摘要持续保留，以支持历史日活查询与去重；可通过下方联系方式申请删除相关数据。
  • 免费次数与解锁状态：与匿名 ID 一并保留，不随 32 天明细清理而删除，以保证次数限制和解锁长期有效；可按第五节申请删除。
  • 基础设施日志及备份：按相应服务的轮转、备份和安全保留机制处理，不与在线业务数据同步即时删除；依法或为安全事件必须保留的数据将在必要期限内保留并限制使用。

五、您的选择与数据删除

  • 您可在搜索前修改、取消勾选或删除关键词，并决定搜索页数。
  • 您可在“稍后再看”中取消收藏或清空当前项目的收藏。
  • 您可通过浏览器扩展管理页关闭网站访问权限、停用或卸载插件，以停止后续页面读取。
  • 如需查询、更正、导出或删除云端身份、项目及其他相关数据，请通过下方邮箱联系。我们会核实请求与匿名身份的关联，并在核实后处理适用请求。

请注意：卸载插件或清除本地数据不会自动删除云端数据，也可能使您失去原匿名身份、无法恢复之前的项目和收藏。如果需要删除或导出数据，建议先联系我们并保留原浏览器中的插件身份。请勿通过邮件发送访问令牌、刷新令牌、账号密码或 API 密钥。

六、政策更新

功能、数据处理方式或服务商发生变化时，我们会更新本页的内容和日期。重大变化会通过产品内或其他适当方式告知，并在需要时征求您的同意。本政策不替代小红书、抖音等第三方平台自身的隐私政策。
